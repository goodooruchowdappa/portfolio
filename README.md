# Companies Directory

Live Demo: [https://your-vercel-app.vercel.app](https://your-vercel-app.vercel.app)

## Features
- Responsive table/cards
- Search + multi-filter (industry, location)
- Sorting & pagination
- Loading/error states
- Centralized API with Axios

## Setup
```bash
npm install
npm run dev
```

## Tech Stack
- React, MUI, Redux Toolkit, Axios, JSON Server
